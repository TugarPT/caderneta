Sincronizar

No outro aparelho, abre a Caderneta → Definições → Receber aqui, e aponta a câmara para este código até chegar aos 100%.

As fotos dos talões ficam neste aparelho (são grandes demais para o QR). Para as levar, usa a Cópia de segurança.

O outro aparelho não tem câmara?

Carrega em “Enviar como ficheiro”. No telemóvel abre a partilha do Android (por exemplo Quick Share, email para ti ou cabo USB); no computador o ficheiro vai para as Transferências. No outro aparelho: Receber aqui → Abrir ficheiro.

No outro aparelho, carrega em Enviar daqui e aponta esta câmara para o código. Mantém-na parada; as partes que falharem voltam a passar.

    Como juntar

    Antes de mudar, a Caderneta guarda como estava, para poderes desfazer.

    Para os dois aparelhos ficarem iguais, envia agora daqui para o outro (lá, carrega em Receber aqui).
